Το σύνολο δεδομένων Α περιλαμβάνει 37 άτομα για την εργασία ReadText και 36 για την εργασία SpontaneousDialogue. Με βάση το σχήμα της 5-fold διασταυρούμενης επικύρωσης, σε κάθε fold αντιστοιχούν περίπου 7--8 άτομα, με 15--16 περιπτώσεις PD (μειοψηφία) και 21 HC (πλειοψηφία).

\textbf{Επιπτώσεις:}

\begin{itemize}
    \item Μεγάλη διακύμανση στα αποτελέσματα ανά fold (τυπικά std $> 0{,}15$)
    \item Περιορισμένη στατιστική ισχύς για τον εντοπισμό μικρών διαφορών
    \item Περιορισμένη δυνατότητα γενίκευσης σε μεγαλύτερο πληθυσμό
\end{itemize}

\section{Περιορισμοί αναγνωριστικών υποκειμένων}

\subsection{Σύνολο δεδομένων Β: Δεν υπάρχουν ταυτότητες υποκειμένων}

Το σύνολο δεδομένων Β περιλαμβάνει 756 δείγματα (192 HC, 564 PD), αλλά δεν παρέχει IDs υποκειμένων. Αυτό συνεπάγεται ότι:

\begin{itemize}
    \item Δείγματα από το ίδιο άτομο ενδέχεται να εμφανίζονται ταυτόχρονα σε train και test (κίνδυνος διαρροής)
    \item Η εκτιμώμενη απόδοση μπορεί να εμφανίζεται καλύτερη από την πραγματική
    \item Δεν μπορεί να αξιολογηθεί με βεβαιότητα η επίδοση σε εντελώς νέα υποκείμενα
    \item Υπάρχει έντονη ανισορροπία κλάσεων (74{,}6\% PD)
\end{itemize}

\begin{quote}
    \label{cav:dataset-b-leakage}
    \textbf{Προειδοποίηση:} Τα αποτελέσματα του συνόλου δεδομένων Β μπορεί να είναι αισιόδοξα, επειδή δεν είναι γνωστό αν υπάρχει επικάλυψη υποκειμένων μεταξύ των folds. Η έντονη ανισορροπία κλάσεων δυσκολεύει επιπλέον την ερμηνεία.
\end{quote}

\subsection{Περιορισμοί σύγκρισης}

Η άμεση σύγκριση μεταξύ των δύο συνόλων δεν είναι απλή, επειδή διαφέρουν ταυτόχρονα σε πολλούς παράγοντες:

\begin{itemize}
    \item στρατηγική cross-validation
    \item μέγεθος δείγματος
    \item είδος ομιλίας
    \item pipeline χαρακτηριστικών
    \item βαθμό ανισορροπίας κλάσεων
\end{itemize}

Βλ. και Προειδοποίηση~\ref{cav:dataset-b-leakage}.

\section{Περιορισμοί εξαγωγής χαρακτηριστικών}

\subsection{Προκαθορισμένο σύνολο χαρακτηριστικών}

Τα χαρακτηριστικά ορίστηκαν εκ των προτέρων με βάση τη βιβλιογραφία και όχι με βελτιστοποίηση πάνω στα διαθέσιμα δεδομένα. Αυτό σημαίνει ότι:

\begin{itemize}
    \item Είναι πιθανό να υπάρχουν πιο κατάλληλα χαρακτηριστικά που δεν συμπεριλήφθηκαν
    \item Οι βασικές παράμετροι εξαγωγής παρέμειναν σταθερές (π.χ. F0 75--500 Hz, 13 MFCCs)
    \item Δεν εφαρμόστηκε επιλογή χαρακτηριστικών (χρήση όλων των 47 ή 78 χαρακτηριστικών)
    \item Δεν εξετάστηκαν πιο σύνθετοι μετασχηματισμοί ή όροι αλληλεπίδρασης
\end{itemize}

\subsection{Υποθέσεις για την ποιότητα ήχου}

Η διαδικασία εξαγωγής χαρακτηριστικών βασίζεται στην υπόθεση ότι:

\begin{itemize}
    \item Το σήμα διαθέτει ικανοποιητικό λόγο σήματος προς θόρυβο
    \item Οι συνθήκες εγγραφής είναι σχετικά σταθερές
    \item Δεν υπάρχει έντονο clipping ή παραμόρφωση
    \item Ο ήχος είναι μονοφωνικός στα 22050 Hz
\end{itemize}

Για το σύνολο δεδομένων Β, οι συνθήκες εγγραφής παραμένουν άγνωστες.

\textbf{Συνέπειες:}

\begin{itemize}
    \item Η απόδοση ενδέχεται να μην είναι η βέλτιστη
    \item Τα αποτελέσματα αποτυπώνουν κυρίως baseline συμπεριφορά
    \item Με διαφορετική ρύθμιση είναι πιθανό να μεταβαλλόταν η κατάταξη των μοντέλων
    \item Η στάθμιση κλάσεων εξετάστηκε ξεχωριστά (σημαία USE\_CLASS\_WEIGHT\_BALANCED)
\end{itemize}

\textbf{Λογική:} Με τόσο μικρό δείγμα (37 άτομα), η nested CV θα οδηγούσε σε πολύ μικρά εσωτερικά folds ($\sim$5--6 άτομα) και συνεπώς σε αυξημένη αστάθεια. Η χρήση σταθερών παραμέτρων υποστηρίζει τη δίκαιη σύγκριση και την αναπαραγωγιμότητα.

\section{Μεθοδολογικοί περιορισμοί}

\subsection{Χωρίς εξωτερική επικύρωση}

Όλα τα αποτελέσματα βασίζονται σε εσωτερική 5-fold διασταυρούμενη επικύρωση, χωρίς ανεξάρτητο εξωτερικό test set. Αυτό επιβάλλει τους εξής περιορισμούς:

\begin{itemize}
    \item Δεν υπάρχει δοκιμή σε ανεξάρτητη πηγή δεδομένων
    \item Δεν υπάρχει επικύρωση σε πολλαπλές τοποθεσίες
    \item Παραμένει άγνωστη η γενίκευση σε άλλες συσκευές ή συνθήκες εγγραφής
    \item Δεν έχει ελεγχθεί η χρονική σταθερότητα (μία συνεδρία ανά άτομο)
    \item Δεν έχει εξεταστεί η γενίκευση σε άλλες γλώσσες ή διαλέκτους
\end{itemize}

\textbf{Αιτιολόγηση:} Βλ. ενότητα~\ref{sec:cv-rationale}.

\subsection{Χειρισμός ανισορροπίας κλάσεων}

Η ανισορροπία κλάσεων ήταν παρούσα και στα δύο σύνολα δεδομένων:

\begin{itemize}
    \item Σύνολο δεδομένων Α: Αναλογία HC:PD 1{,}31:1 (ReadText) και 1{,}40:1 (SpontaneousDialogue)
    \item Σύνολο δεδομένων Β: Αναλογία HC:PD 1:2{,}94 (σοβαρή ανισορροπία)
\end{itemize}

Η επιλογή USE\_CLASS\_WEIGHT\_BALANCED χρησιμοποιήθηκε ως βασική στρατηγική μετριασμού, αλλά:

\begin{itemize}
    \item Δεν βελτίωσε σταθερά όλα τα metrics
    \item Σε ορισμένες περιπτώσεις αύξησε τη διακύμανση
    \item Η καταλληλότερη στρατηγική πιθανόν εξαρτάται από το μοντέλο
\end{itemize}

\textbf{Εναλλακτικές προσεγγίσεις που δεν διερευνήθηκαν:} SMOTE, undersampling ή ρύθμιση κατωφλίου.
