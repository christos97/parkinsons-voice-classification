\section{Research Questions}

The experiments address the following research questions:

\begin{description}
    \item[RQ1:] How do classical ML models perform on PD voice classification using acoustic features?
    \item[RQ2:] Does feature set extension (47 $\rightarrow$ 78 features) improve classification performance?
    \item[RQ3:] Does balanced class weighting improve performance on imbalanced datasets?
    \item[RQ4:] How do results compare between Dataset A (subject-aware CV) and Dataset B (standard CV)?
    \item[RQ5:] Do speech tasks (read vs spontaneous speech) yield different classification performance?
\end{description}

\section{Experimental Matrix}

\subsection{\texorpdfstring{$2 \times 2 \times 5$ Factorial Design}{2x2x5 Factorial Design}}

The complete experimental design crosses three factors:

\begin{enumerate}
    \item \textbf{Feature Set:} Baseline (47) vs Extended (78)
    \item \textbf{Class Weighting:} None (baseline) vs Balanced
    \item \textbf{Model Architecture:} Logistic Regression vs SVM (RBF) vs Random Forest vs Gradient Boosting vs XGBoost
\end{enumerate}

This yields $2 \times 2 \times 5 = 20$ conditions per dataset/task combination.

\section{Experimental Protocols and Reproducibility}

Cross-validation strategies (grouped stratified K-fold for Dataset A, stratified K-fold for Dataset B), evaluation metrics, and statistical reporting are defined in Chapter~\ref{ch:methodology} (Sections~\ref{sec:cv-rationale} and~\ref{sec:eval-metrics}). All experiments used \texttt{random\_state=42} for reproducibility. Dataset B results should be interpreted cautiously due to the absence of subject identifiers (Section~\ref{cav:dataset-b-leakage}). Limitations are catalogued in Chapter~\ref{ch:limitations}.
