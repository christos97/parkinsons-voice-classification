\chapter{Συμπέρασμα}
\label{ch:conclusion}

\section{Περίληψη της εργασίας}

Η εργασία αυτή μελέτησε αν μπορούμε να ξεχωρίσουμε άτομα με νόσο Πάρκινσον (PD) από υγιείς (HC) μόνο από τη φωνή τους, χρησιμοποιώντας κλασικά μοντέλα μηχανικής μάθησης. Η έμφαση δόθηκε σε κρίσιμα μεθοδολογικά ζητήματα, όπως η διαρροή υποκειμένων, η ανισορροπία κλάσεων και η επιλογή χαρακτηριστικών.

\subsection{Συνεισφορές}

\begin{enumerate}
    \item \textbf{Αυστηρή αξιολόγηση:} Χρησιμοποιήθηκε ομαδοποιημένη stratified 5-fold CV, με συστηματικό σχεδιασμό (χαρακτηριστικά $\times$ στάθμιση κλάσεων) και πλήρη αναφορά όλων των συνθηκών.
    \item \textbf{Επέκταση χαρακτηριστικών:} Το σύνολο αυξήθηκε από 47 σε 78 χαρακτηριστικά, με βελτίωση έως +23 ποσοστιαίες μονάδες στο ROC-AUC. Τα πιο σημαντικά χαρακτηριστικά περιλάμβαναν $F_0$, MFCCs και μέτρα αρμονικότητας.
    \item \textbf{Έλεγχος στάθμισης κλάσεων:} Η επιλογή \texttt{class\_weight="balanced"} δοκιμάστηκε σε όλα τα μοντέλα, με μέτρια και μη σταθερά αποτελέσματα.
    \item \textbf{Αναπαραγωγιμότητα:} Χρησιμοποιήθηκαν σταθερός random seed, τεκμηριωμένες παράμετροι και δομημένο workflow.
\end{enumerate}

\section{Βασικά ευρήματα}

\begin{itemize}
    \item Καλύτερο αποτέλεσμα στο σύνολο Α: \textbf{ROC-AUC $0{,}857 \pm 0{,}171$} (Random Forest, εκτεταμένα χαρακτηριστικά, SpontaneousDialogue).
    \item Η επέκταση χαρακτηριστικών βελτίωσε σημαντικά το ReadText (+23pp) και λιγότερο το SpontaneousDialogue (+2,9pp).
    \item Το Random Forest ήταν σταθερά το πιο ανταγωνιστικό μοντέλο.
    \item Παρατηρήθηκε μεγάλη διακύμανση (std έως 0,43), κυρίως λόγω μικρού δείγματος.
    \item Η ομαδοποιημένη CV ήταν κρίσιμη για την αποφυγή αισιόδοξης μεροληψίας.
\end{itemize}

\section{Απαντήσεις στα ερευνητικά ερωτήματα}

\subsection{RQ1: Πόσο καλά αποδίδουν τα κλασικά μοντέλα;}

Η απόδοση έφτασε έως \textbf{$0{,}857$ ROC-AUC}, αλλά με μεγάλη διακύμανση. Σε ορισμένα folds, ειδικά με SVM, το ROC-AUC έπεσε κάτω από 0,5, γεγονός που δείχνει αστάθεια.

Συνολικά, η ταξινόμηση είναι εφικτή, αλλά δεν είναι σταθερή σε μικρά δείγματα.

\subsection{RQ2: Η επέκταση του συνόλου χαρακτηριστικών βελτιώνει την απόδοση της ταξινόμησης;}

Ναι, αλλά η επίδραση εξαρτάται από την εργασία.

\textbf{ReadText:}
\begin{itemize}
    \item Από 0,590 σε 0,822 ROC-AUC (+23pp)
    \item Παράλληλα παρατηρήθηκε μείωση της διακύμανσης
\end{itemize}

\textbf{SpontaneousDialogue:}
\begin{itemize}
    \item Από 0,828 σε 0,857 ROC-AUC (+2,9pp)
\end{itemize}

Τα πρόσθετα χαρακτηριστικά μεταβλητότητας (std και delta-delta MFCC) βοήθησαν κυρίως στο ReadText.

\subsection{RQ3: Βελτιώνει η στάθμιση των κλάσεων την απόδοση σε μη ισορροπημένα σύνολα δεδομένων;}

Όχι ουσιαστικά. Οι μεταβολές ήταν πολύ μικρές (−1,7pp ή −0,1pp) και δεν διαμορφώθηκε σταθερό μοτίβο βελτίωσης.

Η ανισορροπία του συνόλου Α (περίπου 1,3:1) πιθανόν δεν ήταν αρκετά μεγάλη ώστε να απαιτεί στάθμιση κλάσεων.

\subsection{RQ4: Πώς συγκρίνονται τα αποτελέσματα μεταξύ της ομαδοποιημένης και της τυπικής CV;}

\textbf{Σύνολο Α (grouped CV):}
\begin{itemize}
    \item 0,590--0,857 ROC-AUC
    \item Μεγάλη διακύμανση
\end{itemize}

\textbf{Σύνολο Β (τυπική CV):}
\begin{itemize}
    \item 0,940--0,949 ROC-AUC
    \item Πολύ μικρή διακύμανση
\end{itemize}

Το σύνολο Β εμφανίζει πολύ υψηλότερες επιδόσεις, αλλά υπάρχει πιθανότητα διαρροής υποκειμένων. Η grouped CV δίνει πιο συντηρητικές αλλά πιο ρεαλιστικές εκτιμήσεις γενίκευσης.

\subsection{RQ5: Οι εργασίες ομιλίας αποδίδουν διαφορετική απόδοση ταξινόμησης;}

Με βασικά χαρακτηριστικά:
\begin{itemize}
    \item ReadText: 0,590
    \item SpontaneousDialogue: 0,828
\end{itemize}

Με εκτεταμένα χαρακτηριστικά:
\begin{itemize}
    \item ReadText: 0,822
    \item SpontaneousDialogue: 0,857
\end{itemize}

Η αυθόρμητη ομιλία φαίνεται να αποτυπώνει καλύτερα χαρακτηριστικά της PD, αλλά το ReadText ωφελείται περισσότερο από την επέκταση χαρακτηριστικών.

\section{Επιπτώσεις}

\subsection{Για ερευνητές}

\begin{itemize}
    \item Να χρησιμοποιείται grouped CV όταν υπάρχουν πολλαπλές ηχογραφήσεις ανά άτομο.
    \item Να περιλαμβάνονται χαρακτηριστικά μεταβλητότητας.
    \item Να αναφέρονται όλα τα αποτελέσματα και όχι μόνο τα καλύτερα.
\end{itemize}

\subsection{Για επαγγελματίες}

\begin{itemize}
    \item Η φωνητική ανάλυση για PD είναι υποσχόμενη, αλλά όχι ακόμη κλινικά ώριμη.
    \item Το Random Forest αποτελεί καλή baseline επιλογή.
    \item Απαιτείται επικύρωση σε ανεξάρτητα δείγματα.
\end{itemize}

\subsection{Για δημιουργούς datasets}

\begin{itemize}
    \item Να παρέχονται πάντα IDs υποκειμένων.
    \item Να καταγράφονται οι συνθήκες ηχογράφησης και τα δημογραφικά στοιχεία.
\end{itemize}

\section{Μελλοντικές κατευθύνσεις}

Μελλοντικά μπορούν να εξεταστούν:

\begin{itemize}
    \item ρύθμιση υπερπαραμέτρων με nested CV,
    \item επιλογή χαρακτηριστικών,
    \item συνδυασμός διαφορετικών εργασιών ομιλίας,
    \item εξωτερική επικύρωση σε νέα δείγματα,
    \item μελέτη της σοβαρότητας της νόσου.
\end{itemize}

Μακροπρόθεσμα, η φωνητική ανάλυση μπορεί να ενσωματωθεί σε εφαρμογές smartphone μαζί με άλλους βιοδείκτες, όπως βάδισμα και τρόμος.

\section{Τελικό συμπέρασμα}

Η εργασία δείχνει ότι \textbf{η ταξινόμηση της νόσου Πάρκινσον μέσω φωνής είναι εφικτή} με κλασικά μοντέλα και κατάλληλα χαρακτηριστικά, φτάνοντας ROC-AUC έως 0,857 στο σύνολο Α.

Δόθηκε προτεραιότητα στη μεθοδολογική σωστότητα (grouped CV, σταθερές παράμετροι, πλήρης αναφορά διακύμανσης) και όχι στην «εντυπωσιακή» απόδοση. Παρά τους περιορισμούς (μικρό δείγμα, απουσία εξωτερικής επικύρωσης), η εργασία προσφέρει καθαρή και αναπαραγώγιμη βάση για επόμενες μελέτες.
