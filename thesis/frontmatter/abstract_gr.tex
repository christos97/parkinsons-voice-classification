\chapter*{Περίληψη}
\addcontentsline{toc}{chapter}{Περίληψη}

Η νόσος του Πάρκινσον (PD) είναι μια νευροεκφυλιστική διαταραχή που, πέρα από τα κινητικά συμπτώματα, επηρεάζει συχνά και την ομιλία. 

Η εργασία αυτή εξετάζει αν μπορούμε να εντοπίσουμε τη νόσο μέσω της φωνής, χρησιμοποιώντας κλασικές μεθόδους μηχανικής μάθησης.

Για τον σκοπό αυτό χρησιμοποιήθηκαν δύο διαφορετικά σύνολα δεδομένων ομιλίας, με την ίδια διαδικασία ανάλυσης και αξιολόγησης και στα δύο.

Το πρώτο σύνολο δεδομένων, Mobile Device Voice Recordings at King’s College London, περιλάμβανε κατηγοριοποιημένα αρχεία ήχου (WAV) που είχαν καταγραφεί με μικρόφωνα κινητών τηλεφώνων, διαθέσιμα σε καθημερινές συσκευές όπως τα smartphones, και ήταν ήδη χωρισμένα σε δύο ομάδες, δηλαδή άτομα με Πάρκινσον (PD) και χωρίς (HC). 

Οι ηχογραφήσεις ήταν ακατέργαστες, γι' αυτό προχωρήσαμε στην εξαγωγή ακουστικών χαρακτηριστικών για να μετατρέψουμε τα δεδομένα σε μια αριθμητική μορφή που είναι κατάλληλη για επεξεργασία και ανάλυση. 

Το δεύτερο σύνολο δεδομένων, με τίτλο PD speech signal features από το Kaggle (UCI), περιλάμβανε ακουστικά χαρακτηριστικά που είχαν ήδη εξαχθεί σε μορφή csv, 
ετσι σε αυτή την περίπτωση, δεν χρειάστηκε να επεξεργαστούμε τον ήχο αφού τα χαρακτηριστικά ήταν ήδη διαθέσιμα σε αριθμητική μορφή.

Και στα δύο σύνολα δεδομένων, ο στόχος ήταν να διαπιστώσουμε αν τα μοντέλα μπορούν να καταλάβουν ποια άτομα έχουν Πάρκινσον μόνο από τη φωνή τους.

Αξιολογήθηκαν πέντε αλγόριθμοι: Logistic Regression, Support Vector Machine (SVM), Random Forest, Gradient Boosting και XGBoost. 

Επίσης, εξετάστηκε αν το να βάλουμε περισσότερα χαρακτηριστικά βοηθά τα μοντέλα να αποδίδουν καλύτερα και αν η χρήση class weighting βοηθά να υπάρχει πιο σωστή ισορροπία ανάμεσα στις ομάδες PD και HC.

Για να είναι δίκαια και αξιόπιστα τα αποτελέσματα και να μη γίνει κάποιο λάθος με τα δεδομένα, χρησιμοποιήθηκε διασταυρωμένη επικύρωση (cross-validation).

Τα αποτελέσματα έδειξαν ότι ο Random Forest τα πήγε καλύτερα από όλα τα άλλα μοντέλα και ότι, γενικά, όσο αυξάνονταν τα χαρακτηριστικά, τόσο βελτιωνόταν η απόδοση των περισσότερων μοντέλων.

Η εφαρμογή class-weighting βοήθησε κυρίως στον Random Forest ενώ στους άλλους αλγόριθμους είχε μικρή ή αρνητική επίδραση.

Συνοψίζοντας, η μελέτη αποδεικνύει ότι η ανάλυση της φωνής σε συνδυασμό με τις τεχνικές μηχανικής μάθησης μπορεί να συμβάλλει στην αναγνώριση της PD. 
Ωστόσο, τα αποτελέσματα απαιτούν προσοχή, καθώς υπάρχουν ορισμένοι περιορισμοί, όπως για παράδειγμα, 
μπορεί να υπάρχουν πολλές ηχογραφήσεις από το ίδιο άτομο και οι δύο ομάδες δεδομένων ενδέχεται να διαφέρουν σε μέγεθος (ανισόρροπες). 

Με σωστή ανάλυση των δεδομένων και κατάλληλη εφαρμογή αλγορίθμων, ίσως στο μέλλον να είναι εφικτή η αναγνώριση ασθενειών μέσω της φωνής, 
ακόμη και με κοινά μικρόφωνα που χρησιμοποιούμε στην καθημερινή ζωή, χωρίς την ανάγκη ειδικού εξοπλισμού. 
Αυτό έχει μεγάλη σημασία, διότι εάν η ασθένεια ανακαλυφθεί εγκαίρως, μπορεί να ξεκινήσει νωρίτερα η θεραπεία, προσφέροντας στους ασθενείς τη δυνατότητα για καλύτερη ποιότητα ζωής.
