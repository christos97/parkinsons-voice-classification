\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Parkinson's Disease (PD) is a progressive neurological disorder characterized primarily by motor symptoms and secondary by speech impairment.

This paper examines the possibility of diagnosing PD through voice recordings by utilizing only classical machine learning methods.

We used two different datasets and applied the same method of analysis and verification.

The first dataset, included some audio files (WAV), 
that were already split in two groups, i.e., PD and healthy controls (HC), and were recorded with low cost microphones, available in everyday devices like smartphones.

Since the recordings were raw we had to process them to extract the acoustic features related to PD, and then convert the data to a numeric format.

The second dataset, PD speech signal features from Kaggle (UCI), contained pre-extracted acoustic features already in csv format, so we did not need to process the audio ourselves.

We compared five machine learning algorithms, i.e., Logistic Regression, Support Vector Machine (SVM), Random Forest, Gradient Boosting, and XGBoost.

We also determined if additional features in the training set resulted in improved performance, and if class weighting enhanced model performance (particularly for the PD group).

Cross-validation was utilized in each case to prevent data leakage.

The results show that Random Forest algorithm outperformed all other tested algorithms, in almost all cases and that increasing the number of features in the training set positively affected the majority of the tested models.

Class weighting had a small positive impact primarily on Random Forest, while the other four algorithms either did not benefit from class weighting or were even negatively affected.

Class-weighting appeared to have a small positive effect for Random Forest alone. The other four models exhibited no advantage, or they were harmed by class-weighting.

The overall conclusion of this research is that using voice-based analysis in conjunction with machine learning will assist in diagnosing patients who have Parkinson’s disease.

It has to be said that the results need to be interpreted carefully as there are several limitations and constraints (e.g., potentially more than one recording per patient and substantial differences in sample size for the two different data sets).

But even though there are limitations, the study suggests that it is possible to identify diseases through voice if you properly process your data and correctly apply machine learning algorithms.

Early detection can allow treatment to begin earlier and thereby improve the quality of a patient's life.
