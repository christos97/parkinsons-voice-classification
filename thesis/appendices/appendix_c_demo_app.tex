\section{Σκοπός και όρια}

Το παρόν παράρτημα περιγράφει τη διαδικτυακή εφαρμογή επίδειξης που αναπτύχθηκε για την παρουσίαση της ροής \textit{inference} από φωνητικό δείγμα έως πρόβλεψη. Η εφαρμογή έχει αποκλειστικά ερευνητικό και εκπαιδευτικό χαρακτήρα.

\textbf{Κρίσιμη διευκρίνιση:}
\begin{itemize}
    \item Δεν αποτελεί κλινικό εργαλείο και δεν χρησιμοποιείται για διάγνωση.
    \item Οι πιθανότητες εξόδου είναι δείκτες εμπιστοσύνης του μοντέλου, όχι ιατρική απόφαση.
    \item Δεν χρησιμοποιήθηκε για τον υπολογισμό των μετρικών των Κεφαλαίων~5--6.
\end{itemize}

\section{Αρχιτεκτονική}

Η εφαρμογή ακολουθεί απλή αρθρωτή αρχιτεκτονική:

\begin{verbatim}
Flask διεπαφή -> Inference Adapter -> Πυρήνας ML
\end{verbatim}

\begin{itemize}
    \item \textbf{Flask (\texttt{app.py}):} διαχείριση διαδρομών, μεταφόρτωσης/καταγραφής ήχου και προβολής αποτελεσμάτων.
    \item \textbf{Adapter (\texttt{inference\_adapter.py}):} ενιαίο σημείο ελέγχου για προεπεξεργασία ήχου, κλήση μοντέλου και μορφοποίηση εξόδου.
    \item \textbf{Πυρήνας μοντέλου:} χρήση των ίδιων modules εξαγωγής χαρακτηριστικών και πρόβλεψης με τα πειράματα.
    \item \textbf{Κανονικοποίηση ήχου (\texttt{audio\_utils.py}):} μετατροπή κάθε εισόδου σε mono 22{,}050 Hz PCM-16 WAV.
\end{itemize}

\textbf{Αμετάβλητες αρχές:}
\begin{itemize}
    \item Αλλαγή μοντέλου/feature set μέσω ρυθμίσεων, χωρίς τροποποίηση των Flask routes.
    \item Κοινή βάση κώδικα με το πειραματικό pipeline για συνέπεια αποτελεσμάτων.
\end{itemize}

    \item Προβολή ετικέτας, πιθανοτήτων και μεταδεδομένων ανάλυσης.
\end{enumerate}

\section{Ερμηνεία αποτελέσματος}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.95\textwidth]{fig_demo_analysis_result.png}
    \caption{Παράδειγμα οθόνης αποτελέσματος της εφαρμογής επίδειξης.}
    \label{fig:demo-result}
\end{figure}

Η οθόνη αποτελέσματος εμφανίζει:
\begin{itemize}
    \item δυαδική πρόβλεψη (PD/HC),
    \item πιθανότητες ανά κλάση,
    \item βασικά χαρακτηριστικά και μεταδεδομένα,
    \item συνολική σημαντικότητα χαρακτηριστικών του μοντέλου.
\end{itemize}

\textbf{Περιορισμοί ερμηνείας:}
\begin{itemize}
    \item Πιθανότητα μοντέλου δεν ισοδυναμεί με πιθανότητα νόσου.
    \item Η συμπεριφορά αναφέρεται σε δεδομένα παρόμοια με το training distribution.
    \item Δεν υπάρχει κλινική επικύρωση ή κανονιστική έγκριση.
\end{itemize}

\section{Αναπαραγωγιμότητα και συνέπεια}

Η συνέπεια με τα πειράματα διασφαλίζεται από:
\begin{enumerate}
    \item κοινά modules εξαγωγής χαρακτηριστικών,
    \item φόρτωση των ίδιων \texttt{.joblib} artifacts,
    \item ρυθμίσεις μέσω \texttt{config.py},
    \item μοντέλα εκπαιδευμένα με σταθερό random seed.
\end{enumerate}

\section{Σύνοψη}

Η εφαρμογή λειτουργεί ως εργαλείο παρουσίασης της ερευνητικής ροής και της λειτουργικότητας του \textit{inference} pipeline. Δεν αποτελεί διαγνωστικό σύστημα και δεν πρέπει να χρησιμοποιείται για κλινικές αποφάσεις.
